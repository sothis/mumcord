The two [Whiteboard] lines are sent only when the host clicks (starting the board, "Post summary to chat"), as plain text of at most 500 characters, with no link. "Post to chat" sends the board or a selection as an ordinary chat image through Mumcord's normal image sending, so every client shows it inline, like any pasted picture. Too big for the server's image limit: it is offered as a file card instead, and standard clients see a text line. Mumcord users with the plugin see the board and a card instead of the text lines. The board itself travels as plugin data, which standard clients ignore.
