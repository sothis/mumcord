Privacy & Connections

How you connect to other people and what Mumcord loads from outside.

File sharing New

Files come straight from the sender while they are online. Nothing downloads on its own. Blocked people can't send you files.

Shows where the file will be saved before it starts.

Files up to 2 GB can be shared. 1 GB by default. Nothing larger is possible.

Sends only the file's fingerprint (its SHA-256 hash) to malwareanalyzer.com, never the file. The service learns which file you downloaded. A file that isn't found there is not automatically safe.On by default with the Everything on preset, off with Balanced and Maximum privacy.

File transfers always go through the relay, so the other person never learns your IP address. This applies to files only, separately from the general peer-to-peer mode. It needs a relay announced on the server: without one, file sharing is unavailable while this is on.

Files are end-to-end encrypted and checked after download.
